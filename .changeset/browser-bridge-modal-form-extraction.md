### Added
- **Universal Modal, Portal & Form Control DOM Extraction (`src/nexus/shared_tools/browser_extension/background.js`):** Extended `extractTabMarkdownReadOnly()` to serialize `<input>` (with `type="password"` value redaction), `<textarea>`, `<select>` (selected value + options), checkboxes/radios, `<legend>`, `LABEL`/`FORM`/`FIELDSET` boundaries, and custom ARIA widgets (`role="combobox"`, `aria-haspopup="listbox"`, `role="checkbox"|"radio"|"switch"`, `contenteditable="true"`).
- **Non-ARIA Portal & Embedded Frame Support (`background.js`):** Expanded Step 5 to detect `[aria-modal="true"]`, fixed framework/portal overlays (`lux-modal`, Radix/Floating UI portals, `body`/`#__next`/`#root`/`#app` direct children), and standalone `<form>` elements outside selected content roots under `## Active Modal / Dialog`; updated `handleReadTabs()` to inject across `allFrames: true` (with top-frame fallback) and merge non-empty embedded frames.
- **Extension Version-Drift Detection (`manifest.json`, `popup.html`, `popup.js`, `background.js`, `src/nexus/shared_tools/browser_bridge.py`):** Bumped bridge extension to `v1.1.0`, surfaced loaded version in the popup UI and `--status` output (`expected_bridge_version`, `loaded_bridge_version`, `update_required`), and added a stale-extension reload callout in `format_tab_reads_as_markdown()` when Chrome reports a mismatched `bridge_version`.
- **Regression Tests (`tests/test_browser_extension_dom.js`, `tests/test_browser_bridge.py`):** Added Node DOM tests for Luma-style non-ARIA fixed portal modals + form controls, validation error dialogs (`data-testid="error-message"`), truncation budget reservation, `opacity: 0` closed-modal skipping, and password redaction, plus Python unit tests for version-drift warnings and status flags.

### Fixed
- **Dialog Chat Misclassification & Long-Page Modal Truncation (`background.js`):** Replaced overly broad `[data-testid*='message' i]` selector in `MESSAGE_SELECTORS` with chat-specific test IDs and gated chat-thread mode behind `controlsCount < 2` so form dialogs containing error messages render under `## Active Modal / Dialog` instead of `- **Sender:**` chat quotes, and reserved `charBudget` for active modals/overlays so long background pages never push active forms past truncation.
